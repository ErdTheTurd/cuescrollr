For iPhone Duo and iPhone

Script on one screen. Camera on the other.

Cuescrollr is an offline teleprompter. On iPhone Duo the script scrolls on one display while the other shows a front-camera preview and your controls. On a regular iPhone the script sits over the camera, near the lens.

No account. No network. Scripts stay on this iPhone.

On a regular iPhone

The script overlays the camera in a dimmed, rounded panel. Play and pause sit on the preview; Speed, Type size, and Mirror are in a controls sheet so they stay out of the read.

What's in the app

These are the names the app uses.

  • Script library

    Open, add, or edit scripts on this iPhone. Starter scripts are titled “Brief intro” and “Product demo.” A footer in the library reads: “Stored only on this device. Cuescrollr works fully offline.”

  • Auto-scroll

    The script moves at the speed you set. Play starts a 3-2-1 countdown; Pause stops it.

  • Speed

    Labeled Speed, shown in WPM. Default 140. You can set 60 to 220.

  • Type size

    Labeled Type size, shown in points. Default 36 pt. You can set 22 to 64.

  • Mirror

    Flips the script for a reflected glass prompter.

  • Reading guide

    An amber line with a dot at each end sits on the current phrase.

  • Offline

    No sign-in, no analytics, no cloud. The front camera is a local preview only: not recorded, not uploaded.

Privacy

Scripts stay in local storage on this iPhone. Cuescrollr does not use the network, analytics, or cloud sync. The front camera is shown only so you can check framing. Read the privacy policy.
